# 架构

Lumos采用分层架构，从下到上：

```
┌─────────────────────────────────────┐
│  Web前端 (Vanilla JS)               │
├─────────────────────────────────────┤
│  FastAPI REST + WebSocket          │
├─────────────────────────────────────┤
│  Agent主循环 (ReAct)              │
├─────────────────────────────────────┤
│  Providers │ Tools │ Skills │ MCP │
├─────────────────────────────────────┤
│  持久化层 (SQLAlchemy + SQLite)    │
└─────────────────────────────────────┘
```

详细模块说明见spec：`docs/superpowers/specs/2026-09-15-lumos-agent-design.md`
